概要

KAGURA Runtimeは、SUZAKU端末に搭載された神楽NPU上でニューラルネットワークを実行するためのランタイムです。CPU/GPUを占有せずに推論を行えるため、ゲームの描画性能を落とさずにAI処理(超解像、被写体認識、フレーム生成の補助等)を組み込めます。対応形式はONNXおよび当社独自の量子化フォーマット(.kgr)です。

1. モデルを量子化する

付属のCLI kagura-quant でONNXモデルをNPU向けに量子化します。キャリブレーション用データセットを渡すと、精度低下を抑えたINT8/INT4量子化を行います。

terminal
$ kagura-quant model.onnx \
    --precision int8 \
    --calib ./calib_images \
    -o model.kgr

2. モデルをロードして推論する

Upscaler.kt
val runtime = SuzakuGameKit.kagura(context)
val model = runtime.load("model.kgr")

// フレームバッファを入力に推論(NPUで実行)
val output = model.run(inputTensor)

// 使い終わったら解放
model.close()

3. フレーム生成と連携する(OS 4.0+)

Performance APIで frameBoost を有効にすると、OS側のAIフレーム生成が働きます。独自の後処理モデルを挟みたい場合は、KAGURA Runtimeのフックを利用します。ユーザーの安全に関わる制御は回避できません(利用規約参照)。

オンデバイス推論のため、入力データが端末外へ送信されることはありません。プライバシーに配慮した設計です(AI利用方針)。
