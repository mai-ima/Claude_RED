SDK RELEASE NOTES

リリースノート

SUZAKU GameKit SDKの変更履歴です。セマンティックバージョニングに従い、メジャー更新でのみ非互換変更を行います。

v4.2.0 — 2026.05.29

RAI-G4 / KAGURA v4 対応

  • KAGURA Runtimeが神楽NPU v4(120 TOPS)とINT4量子化に対応
  • Performance APIに frameBoost(AIフレーム生成連携)を追加
  • Unreal Engine 5.5プラグインを同梱

v4.0.0 — 2026.05.14

SUZAKU OS 4.0「不知火」対応(メジャー)

  • 非互換: PerfMode.TURBO を廃止し PerfMode.PERFORMANCE / SUZAKU に統合
  • サーマルヘッドルームのコールバック粒度を改善
  • 最小対応をAndroid 12(API 31)に引き上げ

v3.4.0 — 2025.11.06

法人向けデバイス管理連携

  • MDMプロファイルからの性能ポリシー適用に対応
  • Cooling APIに外付け「氷嵐クーラー」連携イベントを追加

v3.0.0 — 2025.05.30

RAI-G3 / 3nm世代対応(メジャー)

  • KAGURA Runtimeを初公開(神楽 v3・75 TOPS)
  • ハードウェアレイトレーシング補助APIを追加
  • 非推奨: 旧 ThermalListener を onThermalHeadroom に置き換え(v4で削除済み)

v1.0.0 — 2024.09.03

GameKit SDK 初公開

  • Performance API・Cooling APIを一般公開
  • Kotlin / C++ / Unity バインディングを提供
非推奨APIは、告知から最低1メジャーバージョンの猶予期間を設けてから削除します。移行方法は各リリースの詳細ドキュメントに記載します。
