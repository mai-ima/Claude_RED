導入事例

現場でSUZAKUがどう使われているか。3つの事例をご紹介します。(事例は架空のデモコンテンツです)

CASE 01 — eスポーツ施設

esports HUB SHIBUYA 様(東京・120台導入)

モバイル部門の常設大会環境としてSUZAKU 3を120台導入。「陣」のプロファイル一括配布により、大会ごとの端末設定作業が従来の3時間から15分に短縮。連戦でも熱によるフレーム低下が発生せず、「機材差への抗議がゼロになった」と運営チーム。

導入構成SUZAKU 3 ×120 / 氷嵐クーラー ×120 / 大会用プロファイル配布ツール
効果大会設営時間 -92% / 熱起因のリプレイ申請 0件 / 機材トラブルによる中断 0回

CASE 02 — 教育機関

学校法人 燕学園 様(神奈川・450台導入)

タブレット更新でTSUBAME Pad 2を450台導入。キッズスペースによる利用制限とMDMでの一括管理により、情報担当教員の管理工数を月40時間削減。6年のセキュリティ更新保証が「更新サイクルを7年に伸ばせる」と評価されました。

導入構成TSUBAME Pad 2 ×450 / MDM構築 / 延長保守5年(バッテリー交換込み)
効果端末管理工数 -40時間/月 / 破損率 従来端末比 -63% / 授業アプリ起動時間 半減

CASE 03 — 映像制作

株式会社ホムラフィルム 様(大阪・35台導入)

ロケ撮影のBカメ・現場プレビュー用にSUZAKU 4を導入。8K/30fps撮影と大盤デスクトップでの即時確認により、現場でのラフ編集が可能に。夏場の炎天下ロケでも録画停止が起きない点が採用の決め手でした。

導入構成SUZAKU 4 ×35 / SUZAKU Dock ×10 / 法人延長保守3年
効果撮影データの現場確認時間 -70% / 熱停止による撮り直し 0件 / 機材運搬量 -30%
