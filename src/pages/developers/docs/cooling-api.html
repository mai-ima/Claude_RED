プリクール(先回り冷却)

レイド戦・ガチャ演出・マップロードなど高負荷が予見できる局面の直前に呼ぶと、旋風ファンが先に回転を上げ、ピーク温度を平均4.2℃抑制できます。

PreCool.kt
val cooling = SuzakuGameKit.cooling(context)

// ボス戦ロード開始時に10秒間のプリクールを要求
cooling.preCool(durationMs = 10_000, level = FanLevel.HIGH)

FanLevel

OFF停止。静音を最優先する演出シーン向け。
QUIET〜12,000rpm(28dB以下)。常用可能な静音動作。
HIGH〜20,000rpm。高負荷戦闘向け。
MAX最大回転(24,000rpm)。ユーザー許可が必要。

※ 実際の回転数は端末世代・温度・電池残量によりOSが最終決定します。ユーザーが「陣」で設定した上限を超えることはありません。

外付けクーラー連携

氷嵐クーラーが装着されている場合、ゲームからペルチェ強度を提案できます。

ExternalCooler.kt
if (cooling.externalCooler.isAttached()) {
    cooling.externalCooler.suggestLevel(CoolerLevel.TURBO)
}

温度イベントの購読

ThermalEvents.kt
cooling.onThermalEvent { event ->
    when (event) {
        ThermalEvent.WARNING  -> hud.showTempIcon()
        ThermalEvent.CRITICAL -> game.autoSave()
        ThermalEvent.RECOVERED -> hud.hideTempIcon()
    }
}
