OPTIMIZATION GUIDELINES

「SUZAKU最適化」認定ガイドライン

「SUZAKU最適化」バッジは、SUZAKU端末で最良の体験を提供するタイトルの証です。取得のための推奨基準と認定プロセスをまとめました。

CRITERIA

認定の推奨基準

領域推奨基準確認方法
性能契約起動時に Performance API で目標fpsを宣言し、実効fpsが目標の95%以上を維持「陣」開発者オーバーレイ
冷却高負荷シーンで Cooling API による事前冷却を実装し、30分プレイでサーマルスロットリングが発生しない持続性能テスト
入力遅延タッチ〜描画のエンドツーエンド遅延が高リフレッシュレート時に基準値以下遅延計測ツール
電力効率目標fps達成時の消費電力が、最適化前比で改善していること電力プロファイラ
解像度・HUD高解像度パネル(2K/175Hz)およびパンチホール/ノッチのセーフエリアに対応UI検証

PROCESS

認定までの流れ

STEP 1

開発者プログラムに登録

無料で登録し、SDKと検証機貸出を利用します。

STEP 2

セルフチェック

上記の基準を「陣」オーバーレイと計測ツールで自己確認します。

STEP 3

申請とレビュー

ビルドと計測レポートを提出。当社エンジニアが実機で検証します(目安10営業日)。

STEP 4

バッジ付与

基準を満たしたタイトルに「SUZAKU最適化」バッジを付与し、ストアで訴求します。

認定タイトルの特典

  • 年次発表会「SUZAKU IGNITE」での紹介機会
  • 新SoC・新OSの早期アクセスプログラムへの招待
