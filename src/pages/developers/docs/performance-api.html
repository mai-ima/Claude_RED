サーマルヘッドルームの監視

onThermalHeadroomは0.0(スロットリング直前)〜1.0(完全に冷えた状態)を0.01刻みで通知します。0.15を下回る前に描画負荷を下げるのが推奨パターンです。

ThermalAware.kt
perf.onThermalHeadroom(intervalMs = 1000) { h ->
    when {
        h < 0.10f -> quality.set(Quality.LOW)
        h < 0.25f -> quality.set(Quality.MEDIUM)
        else      -> quality.set(Quality.HIGH)
    }
}

フレーム統計

FrameStats.kt
val stats = perf.frameStats()
log("実効fps: ${stats.effectiveFps}")
log("AI生成フレーム比率: ${stats.boostRatio}")
log("jank発生率: ${stats.jankPercent}%")

ベストプラクティス

  • 契約はシーン単位で更新する(ロビーは60fps、戦闘は165fps等)
  • SUZAKUモードはユーザー操作起点でのみリクエストする
  • ヘッドルーム連動の品質制御を必ず実装する(契約は保証ではなく優先度)
  • バックグラウンド遷移時はrelease()を呼ぶ
