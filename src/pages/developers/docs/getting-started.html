SDKダウンロード

1. 依存関係を追加する

GameKitはMaven Centralで配布しています。build.gradle.ktsに1行追加してください。

build.gradle.kts
dependencies {
    implementation("jp.suzaku.gamekit:gamekit:4.2.0")
}

2. 対応端末かを確認する

すべてのAPIは非対応端末でno-opになりますが、UI表示の分岐にはisSupportedを使います。

MainActivity.kt
import jp.suzaku.gamekit.SuzakuGameKit

if (SuzakuGameKit.isSupported(context)) {
    // SUZAKU端末: 専用設定メニューを表示
    settingsMenu.add(SuzakuSection())
}

3. 性能契約を宣言する

ゲームのメインループ開始時に、目標フレームレートと性能モードを宣言します。OSはこの「契約」を守るようにクロック・冷却・メモリを調停します。

GameSession.kt
val perf = SuzakuGameKit.performance(context)

perf.requestContract {
    targetFps = 120
    mode = PerfMode.PERFORMANCE
    allowFan = true          // 旋風ファンの使用を許可
    frameBoost = true        // AIフレーム生成(OS 4.0+)
}

// ゲーム終了時に解放
override fun onDestroy() { perf.release() }

4. 実機で確認する

ゲームスペース「陣」のオーバーレイ(開発者モード)で、契約状態・実効fps・サーマルヘッドルームをリアルタイム表示できます。「陣」→ 設定 → 開発者オーバーレイをONにしてください。

検証機をお持ちでない場合、開発者プログラム登録者には検証機の貸出を行っています。お問い合わせからご依頼ください。
